# Клиент-серверное приложение для работы с матрицами

## Описание
Java-приложение, демонстрирующее:
- Сетевое взаимодействие через сокеты
- Сериализацию объектов
- Многопоточную обработку запросов

Клиент генерирует матрицу случайных чисел и отправляет её на сервер. 
Сервер вычисляет сумму нечётных элементов и возвращает результат.

## Компоненты

### Клиент (MatrixClient)
- Графический интерфейс на Java Swing
- Генерация матрицы заданного размера
- Отправка объекта Matrix на сервер
- Получение и отображение результата

### Сервер
Два варианта реализации:
- **SequentialServer** — последовательная обработка клиентов
- **ParallelServer** — многопоточная обработка (ExecutorService)

## Технологии
- Java SE 11+ (Sockets, Serialization, Multithreading)
- Java Swing (GUI)
- Git (version control)

## Запуск

### Компиляция
```bash
javac -d out src/client/*.java src/server/*.java

# Последовательный сервер
java -cp out server.sequentalServer

# Параллельный сервер (многопоточный)
java -cp out server.parallelServer

java -cp out client.MatrixClient
```
## Как использовать
1. Введите количество строк и столбцов (1-999)
2. Нажмите "Создать"
3. Клиент отправит матрицу на сервер
4. В окне отобразится матрица и сумма нечётных элементов
